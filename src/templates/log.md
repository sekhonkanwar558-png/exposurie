# Log

Append-only, newest at the bottom. Every entry opens with a searchable header so
the last few actions can always be found:

```
## [YYYY-MM-DD] ingest | Source title
## [YYYY-MM-DD] query  | The question
## [YYYY-MM-DD] sync   | What was folded in
## [YYYY-MM-DD] schema | What convention changed
```
